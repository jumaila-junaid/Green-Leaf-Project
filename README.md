# 🌿 Green Leaf – Plant Store

A responsive plant-selling website developed as a course project for the **Web Design for Beginners** course offered by the **University of Moratuwa**.

## 🌱 About the Project

Green Leaf is a plant store website designed to present a collection of plants in a clean and user-friendly interface. The website includes plant information, prices, plant care tips, and a contact section.

## ✨ Features

* Responsive website layout
* Hero / welcome section
* About Us section
* Popular Plants section with product details and prices
* Plant Care Tips section
* Plant Collection table
* Contact section
* Interactive web elements

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎓 Course Project

**Course:** Web Design for Beginners
**Institution:** University of Moratuwa
